# fundamentos_python
Bitácora de Aprendizaje: Fundamentos de Python
Este documento sirve como un registro de los primeros pasos que he dado en el mundo de la programación con Python. Aquí explico de forma sencilla qué hice, cómo funcionan las herramientas básicas y qué aprendí al resolver cada ejercicio.

1. El primer contacto: Mostrar información en pantalla
Lo primero que aprendemos en Python es a comunicarnos con la computadora. Para esto usamos una instrucción llamada print. Su función es simplemente proyectar en la pantalla cualquier texto o número que le indiquemos.

Durante las prácticas, noté que la computadora es muy estricta con las reglas:

Las comillas son vitales: Si quiero mostrar un texto, debo encerrarlo entre comillas. Si no lo hago, Python piensa que ese texto es el nombre de un objeto que guardé antes y, al no encontrarlo, se detiene y marca un error.

Los paréntesis son obligatorios: Son como las paredes que contienen la instrucción. Si los quitas, el programa no entiende qué quieres hacer.

Personalización: Aprendí que dentro del print puedo añadir instrucciones extra para que los textos se separen con puntos, guiones o estrellas, y decidir si quiero que el siguiente mensaje aparezca en la misma línea o en una nueva. Incluso se pueden hacer dibujos sencillos usando solo caracteres y saltos de línea.

2. El manejo de los textos
A veces necesitamos que el programa muestre frases que ya incluyen comillas. Esto puede ser confuso para Python porque podría pensar que el mensaje terminó antes de tiempo. Para solucionar esto, practicamos cómo usar diferentes tipos de comillas o símbolos especiales para que el texto se vea exactamente como queremos, permitiendo que palabras específicas resalten dentro de una oración.

3. Python como una calculadora inteligente
Una de las partes más extensas del aprendizaje fue entender cómo Python hace cuentas. No es simplemente poner números; hay que entender que la computadora tiene un orden de prioridades para no equivocarse en el resultado final.

A través de varios ejercicios, comprobé que Python sigue un orden lógico:

Primero resuelve lo que esté encerrado en paréntesis.

Luego calcula las potencias (números elevados a otros).

Después realiza las multiplicaciones y divisiones.

Finalmente, hace las sumas y las restas.

Un detalle interesante es que cuando Python hace una división, aunque el resultado sea un número entero, suele añadirle un punto decimal para ser más preciso. Por ejemplo, en lugar de decir 10, dirá 10.0.

4. El uso de variables: Guardar datos para después
Las variables fueron el descubrimiento más útil. Básicamente, son nombres que elegimos para guardar información y no tener que escribirla una y otra vez.

El caso de las manzanas: En lugar de solo sumar números sueltos, les puse nombres como el nombre de la persona que las tenía. Así, pude sumar el contenido de esas etiquetas para obtener un total. Es mucho más fácil entender un código que dice "total de manzanas" que uno que solo tiene números sin contexto.

Conversiones de medida: Usamos variables para transformar kilómetros a millas. Esto es muy práctico porque guardas el valor de la distancia en una variable y el factor de conversión en otra; si mañana quieres saber cuántos kilómetros son otra cantidad de millas, solo cambias el número inicial y el programa hace el resto automáticamente.

Resolución de fórmulas: También usamos variables para resolver ecuaciones matemáticas. Al darle un valor a una letra, en este caso la x, Python puede procesar fórmulas largas y darnos el valor de la incógnita rápidamente.

5. Reflexiones sobre el proceso
Después de completar estos laboratorios, me quedan claras varias cosas que son fundamentales para cualquiera que esté empezando:

En primer lugar, la importancia de ser ordenado. Un pequeño olvido, como una coma o un paréntesis, hace que todo el trabajo se detenga. Esto te enseña a ser más observador y a leer con cuidado lo que escribes.

En segundo lugar, el valor de los errores. Al principio, ver un mensaje de error asusta, pero luego entiendes que es la forma que tiene la computadora de ayudarte a encontrar dónde te equivocaste.

Finalmente, que la programación no se trata de memorizar códigos raros, sino de entender la lógica detrás de cada instrucción para poder resolver problemas de la vida diaria, como calcular distancias o administrar inventarios de forma automática. """
